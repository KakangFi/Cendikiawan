# SOAL//LAB 2.0

Static web app generator soal SD kelas 1–6.

## Perbaikan
- Tombol Generate otomatis membawa tampilan ke hasil setelah soal dibuat.
- Bank Bahasa Inggris diperluas, termasuk **Public places**, sehingga pilihan 20 soal tidak berhenti di 4 soal karena duplikasi.
- Generator Bahasa Inggris menggunakan variasi pertanyaan agar soal yang dihasilkan tetap unik.
- Jika generator gagal membuat soal, status workspace tidak lagi diam-diam menampilkan hasil kosong.

Tidak membutuhkan server/API; cukup buka `index.html` di browser.
